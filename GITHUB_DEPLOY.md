# GitHub deployment

1. Create a GitHub repository, for example `dot-vibes`.
2. Upload the **contents** of this folder to the repository root. Do not upload only the ZIP file.
3. Make sure `index.html` is visible in the repository root.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
6. Your Pages address will be `https://YOUR_USERNAME.github.io/dot-vibes/`.

GitHub Pages hosts the static landing page. It does not run the Node.js backend or PostgreSQL database; those require separate hosting.
