# . vibes — Production-ready launch template

This repository is structured around the Google Play launch checklist.

## Included
- Android Kotlin + Jetpack Compose
- API 36 target
- Firebase-ready authentication/data structure
- Node.js API foundation
- Live-room/audio provider abstraction
- Chat/realtime architecture
- Wallet/gift/transaction ledger model
- Notification architecture
- Report/block/mute moderation model
- Admin API foundation
- Privacy/Data Safety/Play Store preparation docs
- Release/signing documentation
- GitHub-safe secret handling

## Important
This repository cannot contain your private Firebase, payment, audio-provider, Play signing keys, or Play Console credentials. Those are configured by the owner during deployment.

This is a production template, not a claim that external accounts or human testing have already been completed.
